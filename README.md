# 大航海时代 · 七海远征

基于《大航海时代 IV》贸易、舰队经营、航海士与探索玩法设计的原创 HTML5 + JavaScript 战役。采用逐日航线与回合制海战，具备完整的经营、远航、探索、胜负和存档流程；角色、数值及 SVG 美术为本项目内容，范围不包含原作全部人物剧情与系统。

## 启动与构建

需要 Node.js、Gradle 及运行 Gradle 的 JDK。当前已验证环境为 Node.js 22.22.0、Gradle 9.2.1、JDK 25；开发服务器使用 Node.js 的 `import.meta.dirname`。沿用本机 Bash 用户环境，无需额外下载项目依赖。

在项目根目录、Bash 用户环境中运行：

```bash
npm start
```

浏览器访问 [http://localhost:4173](http://localhost:4173)。无需执行 `npm install`，开发服务器使用 Node.js 内置模块。通过 HTTP 打开游戏，不直接双击 HTML。

```bash
gradle clean build
```

构建校验 JavaScript 语法、模块引用与 SVG 格式，输出：

- `build/site/`：可由任意静态 HTTP 服务托管的完整站点。
- `build/distributions/seven-seas-expedition.zip`：站点压缩包。

游戏没有第三方运行时依赖、后端或账号系统。全部规则在浏览器执行，存档保存在当前浏览器的 `localStorage`；清理站点数据会删除本地进度，可先导出 JSON 备份。

## 内容与玩法

当前包含七海域、24 港口、12 种船型、8 种可独立配装的火炮、6 种船舱、8 位海员、16 种商品、6 种装备、4 种补给、7 类港口设施、7 件海域信物及 83 张原创 SVG。

| 系统 | 可玩内容 |
| --- | --- |
| 海上 | 海图选港、沿海航路、逐日航行、顺逆风与海雾、补给和疲劳、风暴、海盗、救援、打捞、疾病；海战可炮击、接近、拉开距离、近距接舷、防御、维修、撤退 |
| 港口 | 交易所签约及买卖、码头补给与水手招募、酒馆休息及海员招募、造船厂整备、总督府投资、行会限期运货、遗迹探索 |
| 船舱 | 货仓、物资舱、炮台、水兵室、厨房、医务室；在容量、续航、火力与人员保障之间取舍，改装不能导致超载 |
| 火炮 | 旋回小炮、长身蛇炮、半加农炮、9/18/24/32 磅长炮、32 磅卡隆炮；逐炮台混装，舰体承重限制，距离影响伤害，实际配装决定弹耗 |
| 海员 | 船长、航海长、主计长、炮术长、船医；岗位唯一，经验提升能力，装备强化对应技能，港口内任命与换装 |

舰队最多五艘，可买卖船只并升级帆装、装甲。水手承担船只操作，航海士提供岗位加成，两者分别管理。海上每天消耗粮水、增加疲劳，月度结算工资；缺粮缺水及高疲劳会造成伤亡，欠薪会降低士气。

初次游玩可在里斯本签约，买入 10 单位橄榄油，在码头补给后驶往塞维利亚出售。交易所同时显示买卖价、库存、持仓、单位成本及预计盈亏；后续价格随日期、港口和主计能力变化，以当前报价为准。

## 舰船、舰级与火炮配装

进入 **舰队 → 舰船图鉴 / 火炮图鉴** 浏览、筛选与比较；在舰船详情订购后，进入 **我的舰队 → 船舱与火炮配装**。点击任一炮台舱，可预览换炮后的整船火力与齐射耗弹，分别为不同舱位装配火炮。全部 12 种船均有独立 SVG，新增舰型按单桅、双桅、单/双/三层炮甲板和船艉结构区分；8 种火炮采用可辨认的炮管、炮架与支座。

| 舰型 | 本作选取的名义炮数 | 主炮甲板 / 特征 |
| --- | --- | --- |
| 卡拉维尔轻快帆船、卡拉克大型商船、盖伦战舰、远洋福船 | 不套用后期英国舰级 | 早期探索、贸易及武装远航船 |
| 单桅巡逻帆船、双桅横帆军舰 | 非分级船型 | 单桅纵帆 / 双桅横帆 |
| 六级、五级护卫舰 | 28 / 38 | 单层；巡航与护卫 |
| 四级双层军舰、三级战列舰 | 50 / 74 | 双层 |
| 二级、一级战列舰 | 98 / 100 | 三层 |

舰级采用英国海军 18 世纪后期至 1817 年前的代表制式；一级也包括超过 100 炮的舰型。五、六级为护卫舰，四级在 18 世纪末逐渐退出主力战列线。游戏是架空远航，船厂允许跨时代混装；额定炮数属于历史分类，舱位代表抽象炮组。价格、缩编水手、承重和伤害均为游戏数值，SVG 的炮门是结构示意而非逐炮复原。[舰级来源：Royal Museums Greenwich](https://www.rmg.co.uk/stories/maritime-history/rated-navy-ships-17th-19th-centuries)。

- 每艘船的炮架承重限制可装炮型，三级及更大的战列舰支持全部炮型。
- 新建炮台费用 = 700 施工费 + 船型默认炮价。直接换炮收新炮全价，旧炮不折现；购船报价已含默认舱室与火炮。
- 齐射耗弹按每艘船各炮组的弹药系数求和后向上取整，再汇总全舰队。无炮舰不耗弹，无炮舰队不能炮击。
- 海战初始为中距离，“接近”和“拉开距离”每次移动一档并消耗一回合，敌舰照常反击。接舷只在近距离可用。

| 游戏炮型 | 远 / 中 / 近距离伤害倍率 | 配装用途 |
| --- | --- | --- |
| 蛇炮、9/18/24/32 磅长炮 | 1.15 / 1 / 0.8 | 远射；重炮以弹耗与承重换火力 |
| 半加农炮 | 0.65 / 1 / 1 | 中近距离重弹炮击 |
| 旋回小炮、32 磅卡隆炮 | 0.25 / 0.65 / 1.5 | 近战与白刃支援 |

混装例子：双桅军舰用 9 磅长炮加卡隆炮，在远程牵制与近战之间切换；三级战列舰混用 32 磅、24 磅长炮和卡隆炮，取舍伤害、弹耗与近战能力。贸易船保留货仓、物资舱，以轻型长炮自卫。

## 操作、存档与通关

- 海图点击港口或使用目的地列表规划航线；滚轮缩放、鼠标拖动平移，触屏可使用缩放按钮。
- 起航后可暂停、单日推进，或选择 `1× / 3× / 6×`。途经港口会自动衔接下一航段，直到最终目的港；补给不足、疲劳过高或船只不适航时才中途靠港，最终目的地仍保留，可整备后点击“继续前往”恢复原航线。海上事件与战斗会暂停航行，处理后继续。
- `空格` 暂停或继续航行；数字 `1—6` 依次切换航海图、港口、舰队、船舱、海员、航海志。`Esc` 关闭普通弹窗，遭遇与失败界面需完成对应操作。
- 每次有效行动后自动保存。打开“航海档案”可手动保存、导出、导入或重新远航；导出文件为 `七海远征-航海存档.json`。接受当前版本的有效存档；旧版无火炮配置的存档会按船型补入默认炮组，保留原有舱位和进度。
- 每海域访问至少两港、累计 30% 港口份额并探索一处遗迹，即可在该海域遗迹领取信物。集齐七件后返回里斯本，在航海志完成远征；胜利后可以继续自由航行。
- 全部船只沉没、全部水手归零或士气归零会结束远征。可导入此前导出的存档，或重新开始。



## 上传白名单

`.gitignore` 默认忽略所有路径，仅逐项允许当前构建与运行所需的文件，以及根目录 README。新增源码或资源时同步将对应文件加入白名单。

仓库包含 HTML、JavaScript 源码、CSS、83 张原创 SVG、静态开发服务器、`package.json`、Gradle 配置及 `.gitignore`。SVG 是游戏的运行资源，必须随源码保留。

项目没有第三方 npm 依赖或本地依赖包，也不需要生成依赖锁文件。构建使用本机默认 `gradle` 命令。`build/`、`.gradle/`、`node_modules/`、研究文档、截图、验证记录、日志、存档和备份均不上传。
